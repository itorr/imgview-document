# 图片看看 IMGView

轻巧的 Windows 图片查看器。打开图片，直接看看。

- [官网](https://imgview.magiconch.com/)
- [下载最新版本](https://imgview.magiconch.com/download/)
- [更新记录](docs/更新记录.md)
- [问题反馈](https://github.com/itorr/imgview-document/issues)

支持常见图片、动图、PSD、SVG 和相机 RAW 预览，也能直接浏览压缩包中的图片。提供安装版和无需安装的单文件版，优先从 [夸克网盘](https://pan.quark.cn/s/ce0430b2604a) 或 [GitHub Release](https://github.com/itorr/imgview-document/releases/latest) 下载。

官网与安装包支持中文、英文和日文。两种版本均可在右键菜单手动检查更新，发现新版本后显示更新内容，确认后更新。

本仓库保存官网和面向用户的公开资料。历史版本在 [Releases](https://github.com/itorr/imgview-document/releases) 中提供，程序文件不写入 Git 历史。
