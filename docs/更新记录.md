# 图片看看更新记录

## v0.1.0.305 · 2026-10-04

- 提供中英日安装包，安装后可从开始菜单启动，也能选择创建桌面快捷方式。
- 在右键菜单手动检查更新，查看新版本和更新内容，确认后更新安装版或单文件版。

## v0.1.0.303 · 2026-10-04

- 打开常见图片与 GIF、WebP、APNG 动图，直接浏览文件夹和压缩包里的图片。
- 使用无边框窗口看图，滚轮翻页、自由缩放，支持全屏与漫画分页、并页。
- 查看 PSD、SVG 和相机 RAW 预览，放大超大图片时继续查看局部细节。
- 按住 Tab 查看图片信息，使用取色放大镜、颜色通道预览和剪贴板复制粘贴。

## 早期更新

### 2026-10-04

- 完善 JFIF 图片的打开、浏览与文件关联支持。

### 2026-09-27

- 允许按原尺寸打开的小图继续缩小。

### 2026-09-15

- 改善没有内嵌颜色配置的 YCCK 图片颜色。
- 减少无边框窗口缩放时的闪烁与空帧。

### 2026-09-13

- 加入漫画分页、双页并排和结构化图片信息，支持不匹配页面与长图的连续阅读。
- 支持加密 ZIP、7Z、RAR 图片包和 Safari WebArchive；加入另存图片与更多剪贴板格式。
- 加入取色放大镜、CMYK 四色与整体预览，按图片内嵌颜色配置改善颜色显示。
- 扩展 HEIC、HEIF、HIF 系统解码及基础 DNG 预览，完善 PSD、PSB 与高位深 TIFF。
- 放大超大图片时显示局部细节，反复平移更快；改善动图播放节奏与多窗口看图。
- 完善日文界面、鼠标锚点缩放、窗口尺寸与触摸板操作，减少缩放闪烁。

### 2026-09-12

- 加入 GIF、WebP、APNG 动图播放与暂停，以及 PSD、SVG、RAW、超大 TIFF 和 PSB 预览。
- 直接浏览 ZIP、CBZ 和 TAR 系列压缩包，文件名按自然顺序排列。
- 加入长图滚动阅读、旋转翻转、图片信息、RGB 与 Alpha 通道预览。
- 支持带透明度的图片复制粘贴，改善连续翻图和大图缩放体验。
- 修复透明窗口黑边、中文输入法快捷键拦截及部分图片打开崩溃。

### 2026-09-11

- 推出轻量原生看图窗口，支持多窗口、常驻打开与设置记忆。
- 加入无边框全屏、自由缩放、预载和滚轮翻图。
- 支持拖放打开、图片关联、目录排序、背景选择及中英文界面。
